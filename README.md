## Status

> [!IMPORTANT]
> **This project is currently under active development.**
>
> The simulation, controls, architecture, GPU backends, benchmarks, and documentation are still evolving. Features may change, performance results should not be considered final, and pre-v1.0 builds are intended primarily for development and experimentation.
>
> A stable Windows release, reproducible CPU / OpenGL Compute / CUDA benchmarks, and complete documentation will be published with **v1.0.0**.
